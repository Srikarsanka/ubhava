# 🏮 UDBHAVA - Premium Indian Heritage Experience

UDBHAVA is an ultra-premium, AI-driven e-commerce platform dedicated to celebrating Indian handcrafts and heritage. Built with a focus on immersive aesthetics, it transforms the digital shopping experience into a cultural journey.

---

## 🏛️ Autonomous Heritage Intelligence (AFI)

UDBHAVA features a world-first **Autonomous Festival Intelligence** system that dynamically evolves the store UI based on the Indian Lunar Calendar (Panchangam).

- **Real-Time Transformation**: The UI automatically switches between **Saffron (Spiritual)**, **Royal Gold (Diwali)**, and **Lush Green (Spring)** palettes.
- **Cinematic VFX**: High-performance canvas and SVG animations including:
    - **Air Show**: Cinematic jet flypasts with tricolor smoke for Patriotic days.
    - **Abundance**: Falling grains and neem flowers for Harvest and Ugadi.
    - **Divine Light**: Floating diyas and lanterns for spiritual celebrations.
- **AI Copywriting**: Bespoke festival greetings and product curations generated by Gemini.

---

## 🚀 Key Features

### 🛍️ Customer Journey
- **Immersive Shop UI**: Category-based browsing with cultural thematic washes.
- **Smart Checkout**: Support for Card, **Dynamic UPI QR**, and Cash on Delivery.
- **Festival Curation**: Automatic "Auspicious Edits" based on upcoming festivals.
- **Secure Auth**: JWT-protected sessions with HttpOnly security.

### 👨‍💻 Admin Sovereignty
- **Deep Analytics**: Sales forecasting by Month, Quarter, and Year.
- **Report Engine**: Instant export to **PDF** and **Excel**.
- **Inventory Control**: Real-time stock alerts and visual management.

## 📦 Getting Started

1. **Setup Environment**: Create `server/.env` based on `.env.example`.
2. **Install**: `npm install && cd server && npm install`
3. **Seed Intelligence**: `node server/seed.js && node server/syncDynamicFestivals.js`
4. **Launch**: `npm run dev`
